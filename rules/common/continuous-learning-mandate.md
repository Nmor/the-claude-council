# Durable learning

> Size budget: 2 KB.

Record a reusable lesson only after a concrete failure, correction or repeated pattern. Keep project facts in project memory and progress in the existing plan. Do not generate learning candidates or edit global rules after every routine task. Never store secrets or promote one project preference into a universal rule.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/continuous-learning-mandate.md).
Do not preload it for unrelated work.
