# Evidence before fixes

> Size budget: 2 KB.

Reproduce or inspect a failure on its actual path before changing behavior. Trace the smallest useful dependency slice, state uncertainty and use a focused regression. Expand the investigation when the evidence contradicts the hypothesis, not by routinely sweeping every repository.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/diagnose-before-fixing.md).
Do not preload it for unrelated work.
