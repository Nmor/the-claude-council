# Completion criteria

> Size budget: 2 KB.

Complete the user's scoped acceptance criteria, required tests and integrations before claiming completion. Distinguish code written, locally tested, integrated and deployed. Migration claims require the replacement path to work with the replaced dependency stopped. Do not add unrelated audits to a completed task.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/done-criteria.md).
Do not preload it for unrelated work.
