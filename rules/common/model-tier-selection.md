# Model selection

> Size budget: 2 KB.

Respect the user's model and effort choices. Use a cheaper model for a bounded mechanical helper only when the task and available runtime support it; retain capable review for difficult or high-risk work. Do not spawn agents just to distribute work among model tiers. Do not repeatedly retry a known exhausted tier. Model changes require an available supported mechanism, not claims that a hook can switch the session.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/model-tier-selection.md).
Do not preload it for unrelated work.
