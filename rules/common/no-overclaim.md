# Evidence and honesty

> Size budget: 2 KB.

Claims must match evidence. Starting a command, writing a marker, generating a report or installing a file does not prove success. State failures, skips, stale evidence and unsupported runtime behavior. Do not invent independent agent reviews, consensus votes or percentage completion. Preserve valid evidence with its revision/scope rather than rerunning solely to attach a fresh ceremonial block.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/no-overclaim.md).
Do not preload it for unrelated work.
