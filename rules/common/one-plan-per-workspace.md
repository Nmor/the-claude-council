# One authoritative plan

> Size budget: 2 KB.

Use the existing plan named by the user or the project memory's Active plan pointer. Update it in place; do not fork plans for agents or create another after compaction. Read the current handoff and relevant task sections, then consult history only when needed. Preserve requirements and evidence without copying the entire plan into prompts.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/one-plan-per-workspace.md).
Do not preload it for unrelated work.
