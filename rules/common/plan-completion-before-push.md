# Publication scope

> Size budget: 2 KB.

Follow the user's explicit commit/push/deployment policy. User authorization overrides generic workflow conventions. Complete required checks for the changes being published and record outstanding programme work honestly. Do not infer authorization to push other repositories or deploy from permission to publish one repository.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/plan-completion-before-push.md).
Do not preload it for unrelated work.
