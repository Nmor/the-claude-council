# Review changed boundaries

> Size budget: 2 KB.

At a meaningful phase boundary, review the changed behavior and affected cross-phase contracts. Reopen earlier work only when new evidence, changed assumptions or integration risk warrants it. Do not recursively re-audit every prior phase after each small step. Resolve material findings, run relevant checks, update the handoff and move on.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/post-phase-retrospective-review.md).
Do not preload it for unrelated work.
