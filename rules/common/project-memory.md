# Compact project memory

> Size budget: 2 KB.

Keep durable project facts in the project's actual memory location and an explicit Active plan pointer when applicable. Keep progress and current evidence in that plan. At handoff preserve only decisions, current state, unresolved risks and next action. Do not refresh timestamps without updating facts or load another project's most recent session as context.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/project-memory.md).
Do not preload it for unrelated work.
