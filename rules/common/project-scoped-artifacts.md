# Project isolation

> Size budget: 2 KB.

Keep plans, runtime logs, audits and personal identifiers out of public source unless the user explicitly chooses otherwise. Preserve the existing project artifact layout and canonical plan. Do not bootstrap extra folders or duplicate private artifacts merely because a new task begins. Shared rules must remain project-independent.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/project-scoped-artifacts.md).
Do not preload it for unrelated work.
