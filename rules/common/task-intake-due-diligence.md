# Proportionate intake

> Size budget: 2 KB.

Use the user request, existing plan and available project context first. For substantive work identify the concrete objective, affected paths/contracts, material risks, acceptance checks and rollback needs. Ask only missing questions that block a safe next step. Consult the detailed intake checklist for high-risk or unfamiliar work; do not print or repeat twenty-nine questions for every feature or clarification.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/task-intake-due-diligence.md).
Do not preload it for unrelated work.
