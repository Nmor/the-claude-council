# User-facing quality

> Size budget: 2 KB.

For changed UI flows, check usability, accessibility, consistency, error/empty/loading states and the project's design conventions. Use relevant UX specialists when the problem warrants them. Do not redesign unrelated screens or impose a new visual style to satisfy a generic aesthetic checklist.

For each failure, fallback or degraded-guarantee branch, decide what the operator and end user see, where the outcome is recorded and how degradation becomes visible. Resolve that product flow with the behavior, not as a later design task.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/ui-ux-quality-bar.md).
Do not preload it for unrelated work.
