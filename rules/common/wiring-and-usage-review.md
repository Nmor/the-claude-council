# Integration wiring

> Size budget: 2 KB.

Trace new capabilities from their real entrypoint through dependencies to observable behavior. Check registrations, configuration, consumers, error paths and cleanup. For replacement work, test without the old service. Review the affected path once and expand only if evidence reveals additional dependencies; avoid repetitive whole-system sweeps.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/wiring-and-usage-review.md).
Do not preload it for unrelated work.
