## Pattern 7: Slide Design — Duarte + Reynolds + Tufte

Slides are visual aids for a SPOKEN presentation. They are NOT a
written document with bullet points. The corollary: if your
slides could be read instead of presented, write a memo instead.

Principles:

- **One idea per slide.** If you need to communicate three
  ideas, use three slides.
- **Image-heavy, text-light.** A photograph + one phrase beats a
  bullet list every time.
- **No bullet lists.** They're a crutch for unstructured
  thinking. If you must list, use a visual (icons + brief
  labels) or break it into multiple slides.
- **Big type.** Minimum 30pt. If you can't fit text at 30pt,
  rewrite it.
- **High contrast.** Light-on-dark or dark-on-light, never
  low-contrast.
- **Charts: maximise data-ink, minimise chartjunk (Tufte).** No
  3D, no decorative gradients, no unnecessary axes, no
  redundant labels.
- **Annotate, don't decorate.** Every visual element should
  carry information.
- **Reveal progressively.** Don't show the whole slide at once
  if the structure is sequential.

Duarte's "sparkline" structure for the overall talk: oscillate
between "what is" (current reality) and "what could be"
(your proposed future), building tension that resolves at "new
bliss" (the call to action).

## Pattern 8: Heath + Heath SUCCESs Framework

Six attributes of ideas that stick (and how each is often
violated):

| Attribute | Practical move | Violation |
| --- | --- | --- |
| **Simple** | One core message — the "headline" | Burying the lede; listing 12 priorities |
| **Unexpected** | Open a gap in their knowledge; surprise | Predictable opening, standard structure |
| **Concrete** | Specific details, real people, sensory imagery | Abstract jargon, generic descriptions |
| **Credible** | Authority, statistics, vivid example, "Sinatra test" | Vague hand-waving, unsupported claims |
| **Emotional** | Connect to what they already care about | Pure logic without emotional stake |
| **Stories** | Narrative that lets them simulate + recall | List of facts with no human arc |

Test every communication: does it hit S-U-C-C-E-S? Rare to hit
all six; should hit at least 3-4.
