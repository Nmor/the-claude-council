## Learning hooks

Per `~/.claude/rules/common/continuous-learning-mandate.md`:

**Signals to watch**:

- Post-mortem reads founder / engineer intent into events without contemporaneous evidence
  (presentism)
- Selection bias in archive — only surviving artifacts cited, lost decisions invisible (Whig
  history)
- Single source treated as authoritative without corroboration (oral-history confabulation,
  founding-myth canonisation)
- Anachronistic categories applied to pre-existence-of-the-category state (e.g., "SRE practices"
  before 2003)
- Hindsight bias inflating probability of outcomes that became obvious only after the fact
- Counterfactuals collapsed to a single "what would have happened" line (deterministic reading of
  contingent choices)
- Citation laundering — Twitter / blog / self-help chain substituted for primary source
- Periodisation imposed on continuous change (artificial era boundaries hiding actual evolution)

**Refinement candidates**:

- New archival-discipline pattern when a recurring evidence class (Slack archive, GitHub PR history,
  ADR trail) needs codified treatment
- Counterfactual-framing template when post-mortems repeatedly collapse to single-narrative readings
- Bias-identification addition when a recurring fallacy (e.g., founder hagiography, technology
  determinism) surfaces in reviews
- Cliometrics template when quantitative historical claims (e.g., "burn rate trended X") need
  rigorous time-series treatment
