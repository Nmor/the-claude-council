# historical-analysis: Verification Checklist

> The 18-item verification checklist a historical claim runs before it ships. Pointed at by the
> "Verification Checklist" row of the SKILL.md routing table.
>
> **Size budget: 8 KB** — `token-budget.mjs --check`.

## Verification Checklist

- [ ] **Source typology classified**: every cited source identified as primary / secondary /
  tertiary, relative to the specific question
- [ ] **Source criticism performed**: authenticity, integrity, provenance, authorship, position,
  date, bias documented for every consequential source
- [ ] **Archival citations complete**: archive name, collection, box, folder, date, document
  description per Chicago 17th
- [ ] **Periodisation declared**: chosen period boundaries named + justified; alternative
  periodisations acknowledged
- [ ] **Temporal scale specified**: longue durée / conjoncture / événement frame identified;
  cross-scale dependencies noted
- [ ] **Historiography reviewed**: current scholarly conversation on the question summarised; key
  positions named
- [ ] **Counterfactuals (if used) disciplined**: bounded by evidence about decision context; one
  variable changed; plausible at the moment
- [ ] **Triangulation attempted**: claim corroborated by independent sources of different types;
  single-source limitations flagged
- [ ] **Provenance + survival bias acknowledged**: what got preserved + why; what was destroyed +
  suppressed; whose voices are absent
- [ ] **Period categories used**: terms defined in the actors' own conceptual vocabulary;
  anachronisms flagged
- [ ] **Quantitative data published**: data series + processing code available; spreadsheet errors
  checkable (Reinhart-Rogoff lesson)
- [ ] **Oral history consent + archiving**: informed consent obtained, transcript reviewed,
  deposit + accession recorded
- [ ] **Counter-evidence engaged**: strongest opposing reading presented + argued against
- [ ] **Presentism check**: have I judged the past by present standards? Reconstructed past
  categories?
- [ ] **Whig check**: have I treated the present as the inevitable arrival? Acknowledged roads not
  taken?
- [ ] **Hindsight check**: am I describing decisions as obvious because I know the outcome?
- [ ] **Citation discipline**: Chicago 17th notes-bibliography (or appropriate equivalent)
  consistently applied
- [ ] **Original consulted**: for consequential claims, original or verified facsimile examined, not
  just digitised reproduction
