## Cross-References

- **`communication-patterns`** — delivery skills underlying every
  negotiation tactic (tone, channel, written vs verbal, escalation).
- **`okr-framework`** — when internal negotiation is about resource
  allocation, OKRs ground the conversation in outcomes.
- **`compliance-reviewer`** agent / Council Division 6 — contract
  redlines that touch regulatory clauses (data, IP, indemnities).
- **`research-methods`** — preparation discipline: what to learn
  about the counterparty's BATNA + interests.
- **`design-thinking`** — when internal conflict is really about
  problem framing (different people see different problems);
  design-thinking surfaces it.
- **`product-discovery`** — JTBD overlaps with interest-discovery
  in customer-facing negotiations.
- **`ethics`** — the bright-line test for negotiation conduct.
- **`comms-reviewer`** agent / Council Division 16 — written
  outputs (LOIs, term sheets, redlines) get communications review.
