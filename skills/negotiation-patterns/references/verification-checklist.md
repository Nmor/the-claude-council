# negotiation-patterns: Verification Checklist

> The preparation, process, outcome, ethics, relationship and applicability
> checks to run before calling a negotiation principal-level. Pointed at by
> the SKILL.md row "Verification Checklist".
>
> **Size budget: 8 KB** — `token-budget.mjs --check`.

## Verification Checklist

Before declaring a negotiation methodology principal-level,
verify ALL the following:

### Preparation

- [ ] BATNA identified explicitly + (if weak) strengthened
- [ ] Reservation value set quantitatively with conditions
- [ ] Counterparty BATNA estimated + their pressure understood
- [ ] Full issue list compiled (not just price)
- [ ] Importance score assigned per issue (your side + estimate of theirs)
- [ ] Tradeoff candidates identified (issues you value differently)
- [ ] Authority of the person across the table confirmed
- [ ] Cultural research done if cross-border

### Process

- [ ] First offer decision made consciously (you anchor OR you
      let them anchor)
- [ ] Interests probed before commitment to any number
- [ ] Calibrated questions used to surface counterparty interests
- [ ] Labels + mirrors used to defuse emotional escalation
- [ ] MESO presented when issue-importance estimates are uncertain
- [ ] Objective criteria invoked when stuck on a number
- [ ] Every concession paired with a counter-ask
- [ ] Reservation value held when crossed

### Substantive outcome

- [ ] Joint value created (counterparty also got real value),
      not just claimed
- [ ] Agreement is durable (both sides will perform)
- [ ] Implementation mechanics specified (not just principles)
- [ ] Termination + exit terms clear
- [ ] Renegotiation triggers identified
- [ ] Written agreement reviewed by legal where applicable
- [ ] Post-settlement settlement check done

### Ethics

- [ ] No material misrepresentations made
- [ ] No fabricated alternatives quoted
- [ ] Authority + limitations disclosed before signing
- [ ] No use of duress, threats, or bad-faith promises

### Relationship

- [ ] Counterparty would negotiate with you again
- [ ] Any necessary repair of bruised feelings done
- [ ] Follow-up cadence set (next checkpoint, performance review)

### Applicability

- [ ] This is a real negotiation (differing interests, agreement
      required); not just information exchange or dictation
