# research-methods: Verification Checklist

> The checklist run before declaring research principal-level: question + design, sources, methods,
> bias, statistical reporting, reproducibility, ethics, reporting, triangulation. Pointed at by the
> "Verification checklist" row of `SKILL.md`.
>
> **Size budget: 8 KB** — `token-budget.mjs --check`.

## Verification Checklist

Before declaring research principal-level, verify ALL of the
following:

### Question + design

- [ ] Research question stated explicitly + specifically
- [ ] Why the question matters (so-what) named
- [ ] Methodology fit for the question
- [ ] Sample size + selection justified
- [ ] Inclusion / exclusion criteria explicit
- [ ] Ethics review obtained if human subjects

### Sources

- [ ] Primary sources cited (not just secondary / tertiary)
- [ ] Citation discipline tight (consistent style, DOIs where
      available, no stale links, no Wikipedia in citations)
- [ ] Disconfirming evidence actively sought + reported
- [ ] Sources read, not just cited from someone else's bibliography
- [ ] Citation tool used (Zotero / Paperpile / BibTeX)

### Methods

- [ ] Quantitative methods: power analysis + sample size
      justified
- [ ] Qualitative methods: saturation justified + coding
      method named (thematic / grounded / framework)
- [ ] Surveys follow Dillman discipline + pilot-tested
- [ ] Experiments: pre-registered + analysis plan written
      before data collected
- [ ] Causal claims: identification strategy explicit
- [ ] Multiple-comparison correction applied if many tests

### Bias

- [ ] Selection bias addressed
- [ ] Response bias addressed (for surveys)
- [ ] Confirmation bias addressed (pre-registration / blinded
      coding / adversarial review)
- [ ] HARKing prevented (pre-registration / labelled
      exploratory)
- [ ] Publication bias considered

### Statistical reporting

- [ ] Effect sizes reported, not just p-values
- [ ] Confidence intervals reported
- [ ] Practical significance interpreted
- [ ] Replication status acknowledged

### Reproducibility

- [ ] Methods reproducible from description
- [ ] Data shared where possible (respecting privacy)
- [ ] Code shared where applicable
- [ ] Pre-registration on OSF / ClinicalTrials.gov if
      applicable

### Ethics

- [ ] Informed consent obtained for human subjects
- [ ] Privacy + confidentiality protected
- [ ] Conflicts of interest disclosed
- [ ] Funding source disclosed

### Reporting

- [ ] PRISMA flow diagram (for systematic reviews)
- [ ] Audit trail (for qualitative)
- [ ] Limitations section explicit
- [ ] Generalisability bounds stated
- [ ] Disagreement with prior literature engaged

### Triangulation

- [ ] Multiple independent sources cited where stakes are
      high
- [ ] Methodological triangulation where appropriate
- [ ] Disagreements between sources surfaced + addressed
